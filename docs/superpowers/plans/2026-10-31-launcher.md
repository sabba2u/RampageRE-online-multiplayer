# RampageRE Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `RampageRE-Launcher.exe`: a foolproof Windows window that plays, hosts (on Steam, or with a built-in lobby),
joins by code or link, and sets up `rampage://` links.

**Architecture:** One Rust crate in `launcher/`. It has:
- a GUI (eframe/egui);
- a port of the Node lobby's plain-HTTP side (`lobby/src/Games.ts`, `addr.ts`, `http.ts`, without Colyseus), run on a
  thread while hosting and headless with `--serve-lobby`;
- small modules for links (HKCU registry), the game (finding the exe, its build ID, starting it), Steam checks and UPnP.

The game is only started with its existing flags (`--host`, `--steam-host`, `--join`, `--lobby`) and is not changed.

**Tech Stack:**
- Rust 2021;
- crates: `eframe`/`egui` (with `egui_extras` image loaders and `image`, png+jpeg), `tiny_http`, `ureq`, `serde` and
  `serde_json`, `rand`, `winreg`, `igd-next`.
- Node lobby tests: vitest (existing).

**Spec:** `docs/superpowers/specs/2026-10-31-launcher-design.md`

## Global Constraints

- **Windows 10/11, per user only:** registry under `HKCU`, settings in `%LOCALAPPDATA%\RampageRE\launcher.json`. Never
  an admin prompt.
- **No console window:** `#![windows_subsystem = "windows"]`. No PowerShell, nothing to install.
- **The game is only started, never changed.** The offline hash must still start with `CB88DA7AB444D79F` (command in
  `memory/offline-regression-hash.md`; the game's sources are untouched, so this is a final check only).
- **The game comes from next to the launcher** (`RampageRE.exe`, else `RampageRE-dev.exe`), never from a link.
- **The lobby must match the Node lobby on everything the game sees:**
  - routes and their text and JSON shapes;
  - `CODE_ALPHABET = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789"`, `CODE_LENGTH = 5`;
  - `HEARTBEAT_S = 10`, `EXPIRE_S = 30`, `KNOCK_S = 15`, `KNOCKS_KEPT = 8`;
  - `REGISTER_PER_MINUTE = 6`, `GAMES_PER_ADDRESS = 4`;
  - the default port 19980.
- **Link forms:** `rampage://join/<code>`, `rampage://join/<code>@<host[:port]>` (the lobby; port default 19980) and
  `rampage://join/<host[:port]>` (a direct game address). Anything else is refused.
- **Build ID:** FNV-1a 32 over the exe's bytes. It starts at `2166136261`, each byte does `h = (h ^ b) * 16777619`
  (wrapping), and 0 becomes 1. It is shown as `%08X` (as `src/net.c` `build_id`).
- **The copy is exactly as in the spec:** the first-run pop-up, the router pop-up, the Shift+Tab card, the "What's
  Spacewar?" card, the Steam check lines and the Join Game card.
- **Cargo is at `%USERPROFILE%\.cargo\bin\cargo.exe`** (not on the shell's PATH here).

## Review Focus

1. **A friend in the same house uses the internet link,** and the router can't loop back to its own public address.
   Expected: the host's card also shows a "Same Wi-Fi" link with the LAN address. (Test in Task 9.)
2. **The launcher was moved after setting up links.** Expected: it shows "Links point to an old copy" with **Fix**,
   not a green checkmark. (Test in Task 4.)
3. **Port 19980 is already taken** (a Node lobby, or a second launcher hosting). Expected: "Another lobby is already
   running on this PC", and nothing crashes. (Test in Task 2.)
4. **A hostile or broken link:** `rampage://join/K7PQ2@a;calc`, a 2 KB link, letters with accents, `rampage://host/…`.
   Expected: refused with a plain message, and nothing started. (Test in Task 4.)
5. **No game exe next to the launcher.** Expected: every button that starts the game says "RampageRE.exe isn't next to
   the launcher: put the launcher in the game's folder." (Test in Task 5.)
