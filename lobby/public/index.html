Join does nothing? Set up RampageRE links (once per PC)

Windows

  1. Download the setup script.
  2. Right-click it, Run with PowerShell, and pick your RampageRE.exe. Or in a terminal: powershell -ExecutionPolicy Bypass -File install-rampage-links.ps1

Linux

  1. Download the setup script.
  2. sh install-rampage-links.sh /full/path/to/rampage

Your browser may ask once to allow opening RampageRE. Only your user is changed, no admin needed; -Uninstall (Windows) or --uninstall (Linux) removes it.
